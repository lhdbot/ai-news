# 每日市场影响分析（2026-07-29）

## 今日市场信号

- **Agent 工程化正式进入基础设施竞争阶段**：豆包搜索拆分为独立 Agent 服务、Perplexity 把 Windows 电脑变成本地 Agent、360 发布纳米 Work 企业智能体平台，说明行业不再满足于 Demo 级 Agent，开始比拼工具链、权限、可观测性。  
- **“小模型 + Agent 工作流”正在分流纯大模型调用需求**：DeepLens 用多阶段 Agent 让小模型追上前沿大模型，Text-to-SQL 论文用 SFT/DPO 训练模型判断何时启用推理链，说明“用工程手段控成本”成为新共识。  
- **国产开源大模型进入商业推理服务化阶段**：Kimi K3 接入九章云极 Token 工厂并霸榜海外榜单，意味着 Qwen/DeepSeek 之外又多了一个必须关注的国产选项，且开始走企业级推理部署路线。  
- **Agent 安全与权限成为资本押注点**：Cyera 以约 10 亿美元收购 Oasis 补强 Agent 身份与权限管理，企业部署 Agent 时“最小权限 + 可观测”将成为硬需求而非可选项。  
- **资本市场对 AI 基建投入产出比产生疑虑**：谷歌巨额 AI 资本开支引发华尔街不安，大厂烧钱更谨慎，能把 Agent 真正落地并压下推理成本的工程师会更吃香。

**技能价值**

- **部署与推理优化：升值**。Kimi K3 进入推理服务、数据中心限电、华尔街关注 ROI，都指向企业需要会压推理成本的人；你的 vLLM + Docker + CI/CD 组合，加上边缘延迟预测意识，是简历上的硬通货。

**项目机会**

## 风险预警

- **简单 RAG / 单 Agent 问答的护城河正在变浅**：豆包搜索开放、Perplexity 入场、各类 Agent 平台涌现，“会调 RAG 做问答”很快变成基础技能。  
  应对：尽快往“多 Agent 编排 + 领域知识图谱（GraphRAG / Neo4j）+ 成本可控的推理路由”深入，用领域 Know-how 和工程化能力建立壁垒。

- **大厂对 AI 投入产出比敏感，基础岗位可能收缩**：华尔街不安信号说明纯烧算力、缺商业闭环的团队有 freeze / 优化风险。  
  应对：优先选择能直接产生业务指标（客服分流率、研发周期缩短、推理成本下降）的岗位和项目，把经验量化到简历里。
